# 🇺🇦 МАГНАТ.UA — Перша Українська Економічна Онлайн-Стратегія

Преміальна українська економічна онлайн-гра нового покоління в сучасній естетиці **Obsidian Fintech × Aurora Glassmorphism** з реальним WebSocket-мультиплеєром, живими аукціонами, **Смарт-Угодами із Цифровим Підписом**, студійними 3D-ілюстраціями, 3D-кубиками та розумними AI-ботами.

## 🚀 Запуск проєкту

### Режим розробки (Сервер + Клієнт одночасно)
```bash
npm install
npm run dev
```
Відкрийте у браузері: http://localhost:5173

### Продакшн-збірка (для хостингу Render / Railway / Fly.io / VPS)
```bash
npm run build
npm start
```
Єдиний сервер запуститься на http://localhost:3000 (або `PORT` зі змінних оточення) і обслуговуватиме як фронтенд, так і WebSocket-кімнати.
